Research context

A rigid body placed on a rigid base can rock—pivoting alternately about its two bottom corners—when shaken hard enough. The problem appears in seismic engineering, robotics, and classical mechanics through the Housner rocking model.

This site develops the problem from geometry through dynamics, using a smoothstep regularization of the sign function to create a numerically smooth ODE that can be integrated in real time inside a browser. Start with Chapter 1 →
